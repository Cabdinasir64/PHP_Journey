# Safarkayga Barashada PHP

Kani waa repository shakhsi ah oo aan ugu talagalay inaan anigu ku barto luuqadda **PHP**.

Halkan waxaan ku keydinayaa tusaalooyinka koodhka, laylisyada, iyo qoraallada aan sameynayo inta aan ku guda jiro barashada PHP laga bilaabo aasaaska ilaa heer sare, si aan ula socdo horumarkayga.
